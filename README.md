## How to run

1. `generate_probes.py` → produces `redundancy_probes.json`
2. `pipeline_7b.py` (or `pipeline_1b.py`) → run once per checkpoint, produces `results/{stage}.jsonl`

   1. Change the checkpoint after every run.
3. `merge_results.py` → produces the merged, analysis-ready dataset
4. `summary_stats.py` → descriptive tables/figures
5. `mixed_effects_analysis.py` → main statistical test

## Notes

Change the checkpoints in the pipeline 1 or pipeline 2 files to run a different training point.

## Runtime

* On my laptop in Colab T4 GPU, `pipeline1` takes about 20 minutes or less for one of the 3 checkpoints.
* `pipeline2` takes approximately 15–20 minutes per checkpoint on CPU.
* All other files take no more than 1 minute to generate outputs.
